# 1.1 Domain

Domain (hay tên miền) là địa chỉ định danh duy nhất của một website trên Internet, thay thế cho địa chỉ IP dạng số phức tạp, qua đó cho phép người dùng truy cập trang web một cách thuận tiện thông qua một tên dễ nhớ.

Về mặt cấu trúc thì domain có 2 phần:
- Phần đầu là tên thương hiệu
- Phần `.com`, `.org`, `.vn` là định danh quốc gia hoặc loại tên miền

---

# 1.2 Hosting

Hosting là dịch vụ cung cấp cơ sở hạ tầng và không gian lưu trữ trên các máy chủ, cho phép cá nhân hoặc tổ chức xuất bản website và các ứng dụng trực tuyến lên môi trường Internet.

Về mặt kỹ thuật, khi đăng ký dịch vụ hosting là đang thuê một phần tài nguyên phần cứng như:
- Dung lượng ổ cứng
- Băng thông
- RAM

trên một máy chủ vật lý để chứa:
- Mã nguồn
- Cơ sở dữ liệu
- File đa phương tiện của website

Hosting có các tiện ích sau:

- **Tính sẵn sàng:**  
  Đảm bảo website luôn hoạt động ổn định 24/7 để người dùng có thể truy cập bất cứ lúc nào.

- **Tốc độ truyền tải:**  
  Tối ưu hóa thời gian phản hồi máy chủ, giúp nội dung hiển thị nhanh chóng trên trình duyệt người dùng.

- **Khả năng chịu tải:**  
  Duy trì hoạt động ổn định ngay cả khi lưu lượng truy cập tăng đột biến.

---

## Cơ chế hoạt động của Hosting

- Người dùng upload mã nguồn và dữ liệu website lên hosting, sau đó trỏ domain về IP máy chủ để khách truy cập có thể xem website qua Internet.

- Nhà cung cấp chịu trách nhiệm vận hành server, mạng, bảo mật và duy trì hệ thống hoạt động ổn định 24/7.

Loại hosting sử dụng ổ cứng **NVMe** có tốc độ đọc/ghi dữ liệu cao hơn SSD thông thường.

#### Ưu điểm:
- Giảm độ trễ
- Tăng tốc truy xuất dữ liệu
- Website phản hồi nhanh hơn

#### Phù hợp với:
- Website thương mại điện tử
- Website tin tức
- Website có lượng truy cập lớn

---

### 4. Reseller Hosting

Loại hosting cho phép người dùng mua tài nguyên lớn rồi chia nhỏ để bán lại cho khách hàng khác.

#### Đặc điểm:
- Tạo nhiều tài khoản hosting con
- Quản lý khách hàng riêng
- Có thể kinh doanh dịch vụ hosting

#### Phù hợp với:
- Công ty thiết kế website
- Freelancer
- Đại lý bán hosting

---

### 5. Hosting phân loại theo hệ điều hành

Hosting được chia theo môi trường hệ điều hành của máy chủ.

#### Linux Hosting

#### Windows Hosting

# 1.3 SERVER
## Server là gì?

Server là hệ thống máy tính có cấu hình mạnh, hoạt động liên tục 24/7 để:
- Lưu trữ dữ liệu
- Xử lý yêu cầu
- Cung cấp dịch vụ cho người dùng qua Internet hoặc mạng nội bộ

Trong mô hình **Client - Server**, server đóng vai trò cung cấp tài nguyên và dịch vụ như:
- Hosting website
- Quản lý cơ sở dữ liệu
- Email
- Ứng dụng trực tuyến
- Cloud computing

Nhờ khả năng:
- Hoạt động ổn định
- Bảo mật cao
- Xử lý mạnh mẽ

server trở thành nền tảng hạ tầng quan trọng của các hệ thống công nghệ hiện đại.

# 1.5 Colocation

Colocation là dịch vụ cho phép doanh nghiệp đặt máy chủ vật lý của mình tại trung tâm dữ liệu (Data Center) của nhà cung cấp.

Nhà cung cấp sẽ hỗ trợ:
- Điện
- Internet
- Điều hòa
- Hệ thống mạng
- Firewall
- Bảo mật vật lý

Trong khi đó, doanh nghiệp vẫn sở hữu và quản lý hoàn toàn máy chủ riêng.

---

## Ví dụ Colocation

Doanh nghiệp:
- Tự mua server Dell/HP
- Tự cấu hình hệ thống

Sau đó:
- Mang server đến Data Center
- Thuê chỗ đặt máy chủ
- Thuê điện và băng thông mạng

---

## Ưu điểm

- Toàn quyền kiểm soát server
- Bảo mật cao
- Hiệu năng ổn định
- Chủ động cấu hình phần cứng

---

## Nhược điểm

- Chi phí đầu tư server lớn
- Cần đội ngũ kỹ thuật vận hành
- Tự bảo trì phần cứng

---

## So sánh Colocation với Dedicated Server

| Colocation | Dedicated Server |
|---|---|
| Tự sở hữu server | Thuê server của nhà cung cấp |
| Tự bảo trì phần cứng | Nhà cung cấp bảo trì |
| Quyền kiểm soát cao hơn | Quản lý đơn giản hơn |
| Chi phí đầu tư ban đầu lớn | Không cần mua server |
# 2. các thành phần cấu thành
# Các thành phần cấu thành của Server / Hosting

# 2.1 OS (Hệ điều hành)

OS (Operating System) là hệ điều hành dùng để quản lý và vận hành server.

OS chịu trách nhiệm:
- Quản lý tài nguyên phần cứng
- Chạy ứng dụng
- Quản lý file và tiến trình
- Điều phối hoạt động hệ thống

## Các hệ điều hành phổ biến

| Hệ điều hành | Đặc điểm |
|---|---|
| Linux | Phổ biến trong hosting và server |
| Windows Server | Hỗ trợ .NET và MSSQL |

---

# 2.2 CPU

CPU (Central Processing Unit) là bộ xử lý trung tâm của server.

CPU thực hiện:
- Xử lý dữ liệu
- Tính toán
- Thực thi lệnh hệ thống

## Thông số quan trọng
- Core
- Thread
- Xung nhịp CPU
- Cache

CPU càng mạnh:
- Khả năng xử lý càng nhanh
- Chịu tải càng tốt

---

# 2.3 RAM

RAM là bộ nhớ tạm thời dùng để lưu dữ liệu trong quá trình xử lý.

RAM giúp:
- Chạy ứng dụng
- Tăng tốc xử lý dữ liệu
- Hỗ trợ đa nhiệm

## Đặc điểm
- RAM càng lớn → xử lý càng ổn định
- Thiếu RAM → hệ thống dễ chậm hoặc treo

---

# 2.4 DISK (Ổ cứng)

DISK là nơi lưu trữ:
- Hệ điều hành
- Mã nguồn website
- Database
- File dữ liệu

---

## 2.5 SSD

SSD là ổ cứng sử dụng chip nhớ điện tử thay cho đĩa quay cơ học.

### Ưu điểm
- Tốc độ nhanh
- Hoạt động ổn định
- Tiết kiệm điện

---

## 2.6 NVMe

NVMe là công nghệ lưu trữ tốc độ cao hoạt động trên giao tiếp PCIe.

### Ưu điểm
- Tốc độ đọc/ghi cao hơn SSD SATA
- Giảm độ trễ
- Tăng hiệu năng hệ thống

### Phù hợp với
- Website lớn
- Database
- Hệ thống cần xử lý dữ liệu nhanh

---

# 2.7 IP Address

IP Address là địa chỉ định danh của thiết bị trên mạng Internet hoặc mạng nội bộ.

IP giúp:
- Xác định server trên mạng
- Kết nối giữa client và server
- Truyền tải dữ liệu

## Ví dụ

```txt
192.168.1.1
8.8.8.8
```

---

# 2.8 Network Port

Network Port là cổng giao tiếp mạng dùng để trao đổi dữ liệu giữa các dịch vụ.

Mỗi dịch vụ sẽ sử dụng một port riêng.

## Một số port phổ biến

| Port | Dịch vụ |
|---|---|
| 80 | HTTP |
| 443 | HTTPS |
| 22 | SSH |
| 21 | FTP |
| 3306 | MySQL |

---

# 2.9 Datacenter

Datacenter là trung tâm dữ liệu dùng để đặt và vận hành server.

Datacenter bao gồm:
- Server
- Thiết bị mạng
- Hệ thống điện
- Điều hòa
- Firewall
- Hệ thống bảo mật

## Vai trò
- Đảm bảo server hoạt động 24/7
- Cung cấp kết nối Internet ổn định
- Bảo vệ hệ thống và dữ liệu

## Khái niệm

Website sử dụng SSL sẽ có:

```txt
https://
```

thay vì:

```txt
http://
```

---

## Công dụng

- Mã hóa dữ liệu truyền tải

- Tăng độ tin cậy cho website

- Ngăn chặn đánh cắp dữ liệu

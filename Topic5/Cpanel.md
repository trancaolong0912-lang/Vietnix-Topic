## Cpanel

- cPanel là một phần mềm quản trị hosting có giao diện web, giúp quản lý server/website dễ hơn mà không cần dùng nhiều lệnh Linux.
Nó thường được dùng trong hosting shared hosting hoặc VPS.

- cPanel dùng để làm gì?

thao tác bằng giao diện thay vì command line:

Quản lý domain/subdomain
Upload source code website
Tạo database MySQL
Quản lý file (giống File Manager)
Tạo email theo domain
Cài SSL
Backup/restore website
Quản lý FTP
Cài WordPress bằng 1 click
